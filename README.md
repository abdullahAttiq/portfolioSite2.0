# Abdullah Attique — Portfolio (v4)

React 19 + Vite 8 + React Router 7, plain CSS.

- `src/content.js` — original copy (single source of truth, carried over unchanged).
- `src/data/narrative.js` — the hook layer built on top of it: hero stats, the reorg story,
  failure modes, decisions. Everything there is derived from `content.js`.

```bash
npm install
npm run dev
```
